## Booking приложение
Данное приложение - pet-проектом. Цель разработки - демонстрация решения проблем.

## Возможности
- HTTP-сервер на базе Gin;
- endpoint проверки состояния приложения;
- структурированное логирование через slog;
- обработка SIGINT и SIGTERM;
- graceful shutdown;
- запуск через Docker.

## Требования
- Golang 1.27.1;
- Docker - для запуска в контейнере.

## Локальный запуск
Перейдите в каталог проекта:
```bash
cd C:\GoProject\booking
```

Затем установка зависимостей:
```bash
go mod download
```

Запустите приложение:
```bash
go run ./cmd
```

## Запуск через Docker
Соберите Docker-образ:
```bash
docker build -t booking .
```

Запустите контейнер:
```bash
docker run --rm --name booking -p 8080:8080 booking
```
- `--rm` удаляет контейнер после остановки;
- `--name booking` задаёт имя контейнера;
- `-p 8080:8080` публикует порт приложения на компьютере.
